## Selected projects

### [accessible-geometry](https://github.com/hfstrag/accessible-geometry)

Voice-controlled GeoGebra for middle-school students who cannot use a mouse or keyboard. Students build geometric figures by speaking, in French or English, and the application draws them and confirms out loud.

- Speech-to-text with Whisper, followed by an LLM restricted to tool calls (typed Pydantic actions) rather than raw commands
- A planner validates every action against the current figure before translating it into GeoGebra commands, keeping the system predictable and testable
- All-or-nothing execution, clarifying questions on ambiguous requests, deterministic spoken feedback
- Strictly typed, tested offline with fakes, continuous integration on every push

`Python` `FastAPI` `Pydantic` `LLM tool calling` `Whisper` `JavaScript`

### [watermark-detection](https://github.com/hfstrag/watermark-detection)

Detection of subtle periodic patterns hidden in AI-generated images, combining spectral analysis with statistical hypothesis testing to distinguish watermarked images from clean ones.

`Python` `NumPy` `Signal processing` `Statistical testing`

### [ImageConvolution-MPI-GPU](https://github.com/hfstrag/ImageConvolution-MPI-GPU)

Parallel image convolution that distributes work across processes with MPI and offloads computation to the GPU with CUDA, accelerating processing on both CPU clusters and GPUs.

`C` `MPI` `CUDA`
